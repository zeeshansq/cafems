Token Request Rules & Policy Guide

1
⏰ 2:00 PM PKT Daily Cutoff
Requests for tomorrow must be submitted at least 1 day prior by 2:00 PM PKT. Late submissions cannot be processed for next day.
2
🛑 Close (Pause Membership)
Temporarily stops daily token generation for selected dates. You won't be charged for unissued days. (Staff can still issue token at counter via override if you return early).
3
🟢 Open (Resume / Extra Tokens)
Resumes token service or sets custom token count up to max 3 tokens/day. Pre-fills your requested token count at counter.
4
📝 Reason Required
Detailed reason is mandatory for audit log compliance and administrative approval.
